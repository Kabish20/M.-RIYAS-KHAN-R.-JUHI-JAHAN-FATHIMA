## ✨ Rich Islamic Wedding Features & Animations

1. **3D Royal Wax Seal & Envelope Opening Experience**:
   - Guests are greeted with an emerald green royal envelope embossed with golden Bismillah / Tamil praise and a 3D wax seal stamped with the couple monogram `RJ`.
   - Clicking the seal triggers a burst of golden confetti and flower petals, opens the envelope flap in 3D, and starts the soft background wedding melody.
2. **Swaying Moroccan / Islamic Lanterns (Fanoos)**:
   - Ornate SVG lanterns hanging from golden chains with dynamic pendulum swing and pulsing warm golden light.
3. **Falling Golden Sparkles & Jasmine Petals Canvas**:
   - Multi-layered canvas rendering glittering stars and drifting jasmine petals (traditional South Indian wedding flower) and rose petals.
4. **Authentic Islamic Dua & Surah Ar-Rum**:
   - *Barakallahu laka wa baraka 'alayka wa jama'a baynakuma fee khayr* (பாரகல்லாஹு லக வபாரக அலைக வஜமஅ பைனகுமா ஃபீ கைர்).
   - Interactive "Say Ameen" button that showers the screen with blessings and chimes.
5. **Live Countdown Timer**:
   - Real-time countdown to November 23, 2026, 12:00 PM with days, hours, minutes, and ticking seconds.
6. **Bilingual Support (English & தமிழ்)**:
   - 1-click toggle between authentic English and traditional Tamil typography and phrasing.
7. **Interactive Venue Map & QR Code**:
   - Replicates the "Scan For Location" QR code from the invitation card.
   - 1-click "Open in Google Maps", copy address, and embedded interactive map.
8. **Calendar Integration**:
   - 1-click "Add to Google Calendar" and instant `.ICS` file download for Apple Calendar and Outlook.
9. **Guest Personalization (`?to=Name`)**:
   - Any URL with `?to=Janab+Farooq+Family` automatically personalizes the envelope and hero card with their name!
   - Built-in share modal generates customized invite links on the fly.
10. **Wedding Soundtrack & Smooth Cinematic Page Glide**:
    - Plays the provided wedding soundtrack (**Asalayavale** / `music.mp3`) with seamless looping, smooth volume controls, and mute/unmute toggle.
    - Features an **Automatic Smooth Glide**: as soon as the royal envelope is opened, the invitation automatically and smoothly glides down through the ceremony details at a serene pace in sync with the soundtrack.
    - Naturally pauses if the guest manually touches or scrolls the screen.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

Access in your browser at `http://localhost:3000` or `http://localhost:4173`.
To view a personalized invite: `http://localhost:4173/?to=Your+Guest+Name`
